# Project 4: React

## Description

The react project uses fundamental principles to create a frontend web application. The web site that is being built is called "WTWR", which uses weather API to read weather data. The user should be able to determine what to wear based on wheater conditions in their area. This project uses functional components while implementing jsx. The project also uses Vite which is a modern development web tool.

## Technologies and Techniques

- JSX
- React + Vite
- API interactions
- @font-face
